# Project Management

This directory contains project management artifacts for the Pacman project.

## Tracking and Methodology

- **Tooling:** Jira is used for issue tracking, user story estimation, and sprint management (issue keys prefix: `PK-`).
- **Workflow:** jira feature-branch development with peer-review pull requests and automated CI testing before merging into `main`.
- **Documentation:** Sprints, progress tracking against timelines, risk analysis, and team role assignments are documented here.
